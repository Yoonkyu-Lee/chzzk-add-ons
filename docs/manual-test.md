# 수동 확인 시나리오

하니스로 자동화하기 어려운 것만 여기 남긴다.
자동 검증 10개는 `npm run harness`가 돌리고, 목록은 스펙 9.2절에 있다.

각 항목을 확인했으면 날짜와 결과를 옆에 적는다.

## M1. 실제 장시간 연속재생

하니스는 `currentTime`을 끝으로 밀어 전환을 유발한다. 실제 재생과 다를
여지가 남는 지점이다.

1. 짧은 다시보기 두 개(각 10분 이하)를 담는다
2. 첫 항목을 **끝까지 실제로** 재생한다
3. 확인:
   - 종료 10초 전 다음 항목 카드가 뜨는가
   - 8초 뒤 다음 항목으로 넘어가는가
   - 넘어간 뒤 첫 항목이 시청 완료로 표시되는가

## M2. 치지직 자동재생과의 경쟁

하니스에서 **치지직 플레이어는 영상이 끝나면 같은 영상을 처음부터 다시
재생하는 것**으로 관측했다 (`currentTime` 3578 → 1). 다음 영상으로 넘기지
않았다. 실제 사용자 설정에서는 다를 수 있으므로 확인이 필요하다.

1. 치지직 플레이어 설정에서 자동재생을 **켜 둔다**
2. M1을 반복한다
3. 확인: 우리 순서가 이기는가. 지면 패널에 안내 문구를 추가해야 한다

## M3. 로그인 필요 / 구독자 전용 영상

하니스 프로필에는 로그인이 없다.

1. 로그인한 크롬에서 구독자 전용 다시보기를 큐에 담는다
2. 확인:
   - 재생되는가
   - 안 되면 `볼 수 없는 영상입니다`로 표시되고 다음으로 넘어가는가
