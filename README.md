# chzzk-add-ons

치지직(CHZZK)을 크롬에서 시청할 때 부족한 기능을 채워 넣는 크롬 확장 프로그램.

## 다시보기 재생목록

치지직은 다시보기 목록은 제공하지만 재생목록이 없다. 정렬은 최신순과
인기순 둘뿐이고, 연속재생은 최신에서 과거로 거슬러 가는 방향으로만 흐른다.
그래서 한동안 보지 못해 쌓인 방송을 몰아보면 이야기가 거꾸로 흐른다.

이 확장은 다시보기를 담아 **원하는 순서로 이어보게** 한다.

- **전체 담기** — 채널의 모든 다시보기를 오래된 순으로 한 번에 담는다.
  같은 날 여러 조각으로 나뉜 방송도 시각 순서로 정렬된다.
  (예: `등갈비` 14:15 → 15:31)
- **골라 담기** — 카드마다 붙는 버튼으로 하나씩 담고 뺀다.
- **순서 바꾸기** — 패널에서 끌어 옮기거나 ▲▼ 버튼을 쓴다.
- **연속 재생** — 영상이 끝나면 목록의 다음 항목으로 넘어간다.
  끝나기 10초 전에 카드가 떠서 바로 넘기거나 취소할 수 있다.
- **이어보기** — 항목마다 어디까지 봤는지 기억한다. 새로고침해도 유지된다.

큐에 없는 영상을 볼 때는 확장이 **아무 동작도 하지 않는다.** 일반 시청을
방해하지 않는 것이 원칙이다.

## 설치

빌드가 필요 없다. 저장소를 내려받아 폴더를 그대로 로드한다.

1. `git clone https://github.com/Yoonkyu-Lee/chzzk-add-ons.git`
2. 크롬에서 `chrome://extensions` 열기
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 내려받은 폴더 선택

## 사용법

1. 스트리머의 다시보기 목록으로 간다 (`chzzk.naver.com/{채널}/videos`)
2. 목록 위에 생긴 **전체 담기 · 오래된 순**을 누른다
3. 오른쪽 패널에서 순서를 확인하고 **이어서 재생**을 누른다
4. 영상이 끝나면 다음 항목으로 넘어간다

패널은 확장 아이콘을 눌러 열고 닫는다.

## 개발

```bash
npm install
npm run setup:browser   # 검증용 Chrome for Testing 내려받기 (한 번만)
npm test                # 단위 테스트
npm run harness         # 통합 검증 (실제 치지직 방문)
npm run harness:clean   # 남은 검증용 브라우저 정리
```

시나리오 하나만 돌리려면 `node tools/harness.js --scenario 7`.

확장 본체(`src/`)는 **빌드가 없다.** 바닐라 ES 모듈 JS/CSS만 쓴다.
`puppeteer-core`는 검증용 devDependency일 뿐 확장에 들어가지 않는다.

- `docs/superpowers/specs/` — 설계 문서
- `docs/superpowers/plans/` — 구현 계획
- `docs/progress.md` — 진행 기록과 실측으로 알아낸 환경 사실
- `docs/manual-test.md` — 자동화할 수 없는 확인 시나리오
- `CLAUDE.md` — 작업 규칙

### 구조

치지직이 개편되면 고칠 곳을 좁히는 것이 구조의 목적이다.

| 파일 | 책임 |
|---|---|
| `src/common/queue.js` | 큐 순수 로직. DOM·storage·fetch 무의존 |
| `src/common/store.js` | `chrome.storage`를 아는 유일한 파일 |
| `src/common/chzzk-api.js` | API 응답 스키마를 아는 유일한 파일 |
| `src/panel/` | Shadow DOM 패널. 치지직 마크업을 모른다 |
| `src/content/videos-page.js` | 목록 페이지 마크업 의존 |
| `src/content/watch-page.js` | 영상 페이지 마크업 의존 |

치지직 마크업에 의존하는 코드는 `content/`의 두 파일뿐이다.

## 한계

- 치지직의 **비공식 API**와 페이지 구조에 의존한다. 사이트가 개편되면
  동작하지 않을 수 있다. 그런 경우 패널에 무엇이 실패했는지 표시된다.
- 재생목록은 v1에서 **하나**다 (지금 보는 큐). 여러 개, 채널 섞기,
  내보내기는 다음 버전 후보다.
- 기기 간 동기화를 하지 않는다. 큐는 `chrome.storage.local`에만 있다.
