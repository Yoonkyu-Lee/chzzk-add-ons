# chzzk-add-ons

치지직(CHZZK)을 크롬에서 시청할 때 부족한 기능을 채워 넣는 크롬 확장 프로그램.

## 배경

치지직은 "다시보기" 목록은 제공하지만 **재생목록(playlist)** 기능이 없다.
그래서 한동안 보지 못해 다시보기가 쌓인 스트리머의 방송을 몰아볼 때,
최신 → 과거 방향의 자동재생만 가능하고 원하는 순서(예: 오래된 방송부터)로는
이어서 볼 수 없다.

## 목표

- 다시보기를 골라 담아 **원하는 순서로 이어보는 재생목록**
- 재생목록 저장 / 이어보기 (어디까지 봤는지 기억)
